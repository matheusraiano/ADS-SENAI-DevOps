## 📚 Sobre o projeto

Este repositório foi criado para organizar os estudos, atividades, anotações e exercícios desenvolvidos durante o curso de **Análise e Desenvolvimento de Sistemas (ADS) no SENAI**, com foco nos conteúdos relacionados a **DevOps**.

A proposta é manter os materiais organizados e versionados utilizando **Git e GitHub**, acompanhando a evolução dos estudos ao longo do curso.

## 🎯 Objetivos

* Organizar os conteúdos e atividades das aulas;
* Registrar anotações e aprendizados;
* Praticar o uso do Git e GitHub;
* Desenvolver conhecimentos relacionados à cultura DevOps;
* Acompanhar a evolução dos projetos e exercícios;
* Manter um histórico das atividades desenvolvidas durante o curso.
